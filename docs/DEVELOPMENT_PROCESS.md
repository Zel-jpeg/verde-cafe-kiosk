## Working Git/GitHub sequence

1. Create the shared repository and ensure the instructor can access it.
2. Clone it locally; track organized source, assets, and documentation.
3. Assign real feature work and develop it on identifiable branches.
4. Push each branch; open a PR naming its source branch and integration target.
5. Obtain a review before merge and address requested changes.
6. Merge completed feature PRs into the integration branch.
7. Demonstrate the build from the recorded final integration commit.

The history must show at least **seven real development stages**, covering setup, interface, core functionality, validation, bug fix, refactoring, and documentation, with meaningful commit messages. These are categories of actual work, not seven artificial commits to manufacture. The exam p. 6 and checklist p. 4 explicitly require genuine process evidence.
